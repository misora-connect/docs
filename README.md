# docs

misora-connect のユーザー・開発者向けドキュメントリポジトリです。

## 本番サイト

https://misora-connect.github.io/docs/

GitHub Pages で公開しています。`main` ブランチに変更がマージされると自動的にデプロイされます。

## ドキュメントの更新方法

1. このリポジトリをクローンする
2. `docs/` ディレクトリ内の Markdown ファイルを編集する
3. プルリクエストを作成し、`main` ブランチへマージする
4. マージ後、GitHub Actions により自動的に本番サイトへ反映される

## ディレクトリ構成

```
docs/
├── index.md          — トップページ
└── api/
    ├── index.md      — API ドキュメント トップ
    ├── getting-started.md
    ├── user-guide.md
    └── reference.md
```
